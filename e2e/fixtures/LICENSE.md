# Test footage

`test-video.webm` is original, silent geometric footage generated by
`scripts/create-fixture.mjs` for ClipLab. It uses no third-party assets.
The author dedicates this test fixture and its generation script to the public
domain under CC0 1.0 Universal: https://creativecommons.org/publicdomain/zero/1.0/

Duration: 12 seconds. Format: WebM / VP9, 480 × 270, 2 fps.
This is an automated-test fixture and is not shipped in the application bundle.

`identity.cube` and `channel-cycle.cube` are original synthetic RGB tables created
for ClipLab tests and dedicated to the public domain under CC0 1.0 Universal.
They test neutral output and RGB channel ordering; they are not camera conversion
LUTs. The tests also generate a synthetic 33-point nonlinear table in memory.

`export-av.mp4`, `export-sdr-10bit.webm`, `export-sdr-10bit.mp4`, and
`export-hdr-10bit.webm` are original synthetic footage generated by
`scripts/create-export-fixtures.mjs` and dedicated to CC0 1.0 Universal.
They contain geometric patterns, grayscale ramps, and a generated sine tone.
The HDR-tagged ramp tests metadata handling, not HDR mastering quality.
